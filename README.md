# Licencias LavaPro · ISA Soporte

Archivo `licencias.json` que leen todas las instalaciones de LavaPro.

- Los sitios van cifrados: no se puede saber qué lavanderías son clientes.
- Para renovar o suspender usa la herramienta privada `ISA-Soporte-Licencias.html` → "Descargar licencias.json" → aquí: *Add file → Upload files* y reemplazar.
- Los cambios se aplican en unos 5 minutos y **no gastan créditos de Netlify**.
